# Castlevania2DPrototype

Прототип 2D-игры в духе Castlevania / metroidvania на **Unity 6000.0.78f1**. Сайдскроллер: деревенский хаб, подземный данж, бои, лут, сохранения за Слёзы Мары и мини-игра в тафл.

Игровые тексты и диалоги — на русском.

---

## Сцены

| Сцена | Назначение |
|--------|------------|
| `MainMenu` | Стартовое меню, переход в игру |
| `Hub` | Деревня-хаб: изба, лавка варяга, тотемы перехода |
| `Prototype` | Основной геймплей: данж, враги, боссы, лифт, сохранения |
| `SaveLoadMenu` | Пять слотов сохранения / загрузки (открывается с идола или после смерти) |
| `Hnefatafl` | Партия в тафл (9×9) со ставкой монет против варяга |

Переход между хабом и данжем — через тотемы (**F**). Инвентарь между сценами сохраняется в сессии.

## Управление

| Действие | Клавиши |
|----------|---------|
| Ходьба | A / D или стрелки |
| Прыжок | Пробел |
| Удар (комбо из трёх) | ЛКМ |
| Блок | ПКМ |
| Верхний блок / отбить камень сверху | **W + ПКМ** |
| Перекат / скольжение на животе | Left Shift (удерживать, чтобы скользить) |
| Лазание по верёвке | вертикальная ось (W / S), когда персонаж касается каната |
| Подобрать лут / говорить / дверь / сохранить / позвать спутника | **F** |
| Зелье лечения | **1** |
| Мешок спор (прыжок выше) | **2** |
| Инвентарь (держать) | **I** |
| Журнал подсказок | **ё** (`~`) |

Пока открыт свиток подсказки, диалог или меню сохранения, управление персонажем блокируется. Свиток ставит игру на паузу.

## Персонаж

**HeroKnight** — рыцарь со щитом.

- Ходьба, прыжок, стена (wall slide), перекат и удержание скольжения на Shift.
- Три удара в комбо. Щит выдерживает ограниченное число блоков, затем ломается до восстановления.
- Верхний блок (W + ПКМ) закрывает от камней сверху и отражает их — так камень орла можно забросить в корзину.
- Подбор лута с анимацией (щит за спиной). Пока идёт подбор, нельзя ходить и бить.
- Лазание по висячим канатам без «прилипания» к якорям.
- Полоски здоровья и прочности щита на HUD.

## Компаньон — Стручок

В данже прячется **Стручок**. Первый подход открывает свиток; дальше его зовут **F**.

- Выходит из укрытия, идёт следом, копирует прыжки игрока.
- Сам подбирает лут (быстрее игрока).
- В бою прячется, после боя возвращается.
- Не застревает в мобах и тайлах; на стыках наклонных блоков прыгает; с обрыва падает, а не «стоит в воздухе».
- Бессмертен (без здоровья и боевых коллайдеров).

## Предметы

Стартовый запас при входе в Prototype / Hub: **10 Слёз Мары** и **500 обычных монет**.

| Предмет | Зачем |
|---------|--------|
| Обычный лут / монеты | Валюта, в том числе ставки в тафл |
| Слеза Мары | Одно сохранение на идоле = одна слеза |
| Зелье | Лечение с хотбара (**1**) |
| Мешок спор | Падает с грибов, лежит на земле; **2** даёт усиленный прыжок и пыль у ног |
| Добыча энта | Отдельный дроп с энтов |
| Ключ лихо | Гарантированно падает с Гигантского Лихо; открывает ящик механизма лифта |

Лут с земли игрок берёт **F** (без всплывающей иконки). Стручок подбирает сам. После смерти врага вещи выпадают на землю.

## Бой и враги (Prototype)

- **Энт** — ходит по земле; если пол пропадает, падает. Из порталов колдуна тоже падает, если убрать опору.
- **Мухомор** — ближний бой, дропает мешок спор.
- **Мышь** — пикирует на игрока.
- **Орёл** — летает по горизонтали, кидает камень; камень можно отбить верхним блоком в каменную корзину.
- **Лихо** — спит, при агро встаёт и бьёт ногой (сильный отброс).
- **Гигантское Лихо** — патруль, таран в стену, прыжок с экраном, ближний удар; с него падает ключ.
- **Змея** — контакт по капсуле (не по хитбоксу атаки): касается — игрок умирает.
- **Колдун** — замечает игрока, открывает два портала (энты и мухоморы), цикл атаки и отдыха. Корзины + рычаг глушат порталы и сажают его в покой.
- **Цветок (босс Flower)** — щупальца, отдельная арена; состояние пишется в сейв. С босса падает пачка Слёз Мары.

Урон по игроку — через хитбоксы и контакт. Блок и верхний блок режут входящий урон / отражают снаряды.

## Данж Prototype — механики уровня

- Каменный и глиняный тайлсеты (32 px), наклонные блоки в обе стороны, параллакс-фоны.
- **Каменные корзины**: орёл бьёт в них камнями (5 попаданий = полная). Когда обе полные, первый этап рычага; второй удар мечом роняет корзины на порталы и глушит призыв колдуна.
- **Ящик механизма лифта**: без ключа лихо — надпись «Нужен ключ». С ключом **F** открывает оверлей, рычаг внутри запускает лифт.
- **Деревянный лифт**: три каменные площадки, спуск только если пассажир внутри кабины. После рычага кабина едет вниз.
- **Верёвки** для лазания.
- **Идолы сохранения**: **F**, каждое сохранение тратит Слезу Мары. 5 слотов. Смерть тоже выводит в меню слотов.
- Тотем варпа в хаб (**F**).

Подсказки-свитки (один раз, потом в журнале **ё**):

1. У скелета — отбить предмет **W + ПКМ**.
2. У Стручка — позвать спутника **F**.
3. У первого идола — сохранения тратят Слёзы Мары.

## Хаб (деревня)

- Улица с параллакс-слоями, изба, интерьер.
- Двери **F**: вход/выход из избы.
- **Варяг** в лавке: диалог, можно сыграть в тафл или уйти.
- Тотем обратно в Prototype.

Диалоги — оверлей-свиток с именем, текстом и вариантами ответа (**F** / Enter подтвердить, W/S выбрать).

---

## Сохранение

- 5 файловых слотов (`Saves/` на диске).
- Пишутся: позиция и здоровье героя, инвентарь, зелья, босс-цветок, корзины, рычаг, лифт, колдун, лежащий в мире лут.
- Сохранение только с идола и только за Слезу Мары.

---

## Тафл (Hnefatafl)

- Доска 9×9, правила захвата как в Viking Game.
- Сторона игрока случайная; ходят сначала нападающие.
- Перед партией обе стороны ставят одинаковую ставку монетами.
- После матча — рестарт или возврат в лавку варяга.

---

## Интерфейс

- Здоровье и щит.
- Хотбар слева снизу: слот 1 зелье, слот 2 мешок спор.
- Инвентарь 6×4 по удержанию **I**.
- Свиток подсказки с кнопкой X (пауза мира).
- Журнал всех уже найденных подсказок на **ё**.
- Всплывающая **F** у дверей, NPC, тотемов и ящика — это взаимодействие, не туториал.

### Правила Unity

| Делать | Не делать |
|--------|-----------|
| Коммитить `Assets/**` вместе с `*.meta` | Коммитить `Library/`, `Temp/`, `Logs/` |
| Один человек правит одну сцену в один момент | Параллельно править `Prototype.unity` вдвоём |
| Выносить контент в префабы | Резолвить конфликт сцены «на глаз» без Play Mode |

Не открывайте вложенную папку `Assets` в Hub — только корень репозитория.
